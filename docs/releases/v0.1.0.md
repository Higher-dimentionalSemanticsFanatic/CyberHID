## CyberHID 0.1.0

First release. CyberHID adds HID game controllers (pedals, wheels, flight
sticks, throttles, button boxes) to the XInput gamepad Cyberpunk 2077
reads: triggers take the larger value of the gamepad and the bound
inputs, stick axes add up, buttons combine. It works next to a gamepad or
with mouse and keyboard alone.

- Bindings are set in the game under **Settings › Mods › CyberHID**:
  **Controller 1** to **4**, then **Axis**, **Button** or **Hat** on that
  controller, with **Invert**, **Deadzone (%)**, **Response** and **Stick
  range** per analog input. Changes apply within a second, also while the
  game runs.
- `red4ext/plugins/cyberhid/status.json` lists each controller's number,
  its axes and where they are now, and the inputs last moved, so pressing a
  pedal once shows which axis number it is.
- Needs RED4ext and Mod Settings (which needs redscript and ArchiveXL).
  Uses no game offsets, so it does not depend on the game version.

Pre-release: not yet confirmed in game with real controllers. The Mod
Settings save file it reads was worked out from Mod Settings itself. If
bindings don't apply, `status.json` (`menu_saved`, `bindings`,
`active_bindings`, `missing`) shows how far it got.
