## CyberHID 0.2.0

Bindings move from the Mod Settings menu to a **CyberHID** window in the
Cyber Engine Tweaks overlay, laid out like a flight simulator's controls
page.

- **Controllers**: every game controller with an icon and type (wheel,
  pedals, rudder pedals, flight stick, throttle, button box, gamepad),
  read from its HID usages and name. Select one to see its axes, buttons
  and hats live, the first two axes of a stick as a dot in a square, and
  what each input is bound to.
- **Bindings**: each gamepad input with what it is bound to and what
  CyberHID sends for it now. **Scan for input** binds the next axis or
  button moved on any controller; a pedal resting at the top gets
  **Invert** set. Per binding: **Controller**, **Input**, **Invert**,
  **Deadzone**, **Response** (with its curve) and **Range**, with the
  input and output shown live. Several bindings per gamepad input.
- **Settings**: **Enabled**, **Gamepad slot**, **Report a gamepad when
  none is connected**, and what the plugin hooked.
- Under Proton the window says when controllers may be reaching the game
  through SDL; CPMX2077 sets `PROTON_ENABLE_HIDRAW` for them.

Needs RED4ext and Cyber Engine Tweaks; Mod Settings, redscript and
ArchiveXL are no longer needed. Upgrading from 0.1.0: delete
`r6/scripts/cyberhid`, then bind again in the new window (bindings from
the old menu are not carried over).

Pre-release: not yet confirmed in game with real controllers. The plugin
was run under Wine with a stand-in RED4ext loader and the window was
rendered with Dear ImGui from sample data, not inside CET.
